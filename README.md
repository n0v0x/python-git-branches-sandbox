# Git Sandbox

A public educational repository for practicing Git and GitHub.

Here I experiment with:

    cloning repositories;
    creating and switching branches;
    adding and modifying files;
    creating commits;
    merging branches;
    resolving conflicts;
    pushing changes to GitHub;
    creating pull requests;
    working with tags and releases;
    other Git commands and features.

This repository is used as a sandbox, so its contents, commit history, and branch structure may change frequently
